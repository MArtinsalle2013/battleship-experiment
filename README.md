# Battleship

A single-player Battleship game playable in a browser against an AI opponent.

## Features

- Classic 10x10 grid for both player and AI
- Manual ship placement by clicking (press R to rotate)
- Ships: Carrier (5), Battleship (4), Cruiser (3), Submarine (3), Destroyer (2)
- AI places ships randomly and takes turns automatically
- Smart AI: hunts around hits, follows ship direction, uses checkerboard pattern
- Clear visual feedback: hits (red), misses (grey), sunk ships called out
- New Game button to restart
- Responsive design

## How to Play

1. Place your ships on the left board by clicking. Press **R** to rotate between horizontal and vertical.
2. Once all ships are placed, click cells on the enemy board (right) to fire.
3. The AI fires back after each of your shots.
4. Sink all 5 enemy ships to win!

## Running Locally

Open `index.html` in any modern browser. No build step required.
